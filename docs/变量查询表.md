## 一、数据库模型（`backend/app/models.py`）

### 1.1 Scenario（剧本）

| 变量名 | 中文翻译 | 含义 |
|---|---|---|
| `id` | 主键 | UUID 唯一标识 |
| `name` | 剧本名 | 剧本名称，如"无光的灯塔"，唯一 |
| `source_path` | 源文件路径 | 剧本 Markdown 文件路径 |
| `metadata_` | 扩展元数据 | JSON 格式的附加信息 |
| `created_at` | 创建时间 | 记录创建时间戳 |

### 1.2 Character（角色卡）

| 变量名 | 中文翻译 | 含义 |
|---|---|---|
| `id` | 主键 | UUID 唯一标识 |
| `scenario_id` | 所属剧本ID | 外键，关联 Scenario |
| `name` | 角色名 | 角色名称 |
| `archetype` | 原型 | 角色原型，如"调查局探员"、"古董商" |
| `occupation` | 职业 | 角色职业 |
| `hp_current` | 当前生命值 | 当前 HP |
| `hp_max` | 最大生命值 | 最大 HP |
| `san_current` | 当前理智值 | 当前 SAN |
| `san_max` | 最大理智值 | 最大 SAN（通常 99） |

| `skills` | 技能字典 | JSONB，如 `{侦查:60, 聆听:50}` |
| `inventory` | 初始物品列表 | JSONB，角色初始携带的物品 |

### 1.5 AgentTraceRun（Agent 监控运行）

> 一条 `AgentTraceRun` 代表一次完整的玩家行动或助手请求。  
> 学习时可以把它理解成“一次可回放的 Agent 调用链”。

| 变量名 | 中文翻译 | 含义 |
|---|---|---|
| `id` | 主键 | UUID 唯一标识 |
| `session_id` | 会话ID | 所属游戏会话，可为空 |
| `source` | 来源 | `action` 表示玩家行动，`assistant` 表示游戏助手 |
| `status` | 运行状态 | `running` / `success` / `error` |
| `metadata_` | 扩展元数据 | 保存运行级信息，如是否流式、原始输入摘要 |
| `started_at` | 开始时间 | 运行开始时间 |
| `ended_at` | 结束时间 | 运行结束时间，运行中可为空 |

### 1.6 AgentTraceRecord（Agent 监控步骤）

> 一条 `AgentTraceRecord` 代表一次 run 内的一个具体步骤。  
> 例如 `PlannerAgent.generate_plan`、`SkillTool.RuleCheckTool`、`GuardAgent.reflection_review`。

| 变量名 | 中文翻译 | 含义 |
|---|---|---|
| `id` | 主键 | UUID 唯一标识 |
| `run_id` | 运行ID | 所属 `AgentTraceRun` |
| `sequence` | 步骤序号 | 同一次 run 内从 1 递增 |
| `session_id` | 会话ID | 冗余保存，便于按会话筛选 |
| `source` | 来源 | `action` / `assistant` |
| `agent_name` | Agent 名称 | 如 `ContextAgent`、`SkillTool`、`GameAssistantAgent` |
| `step_name` | 步骤名 | 如 `parse_intent`、`generate_plan`、`ContextSearchTool` |
| `phase` | 阶段 | 如 `context`、`plan`、`execute`、`tool`、`guard` |
| `status` | 步骤状态 | `success` / `warning` / `error` |
| `input_payload` | 输入快照 | 安全序列化后的步骤输入 JSON |
| `output_payload` | 输出快照 | 安全序列化后的步骤输出 JSON |
| `error` | 错误信息 | 步骤异常文本，正常时为空 |
| `duration_ms` | 耗时毫秒 | 步骤运行耗时 |
| `created_at` | 创建时间 | 记录创建时间戳 |

### 1.7 AgentTraceSettings（Agent 监控设置）

| 变量名 | 中文翻译 | 含义 |
|---|---|---|
| `id` | 设置ID | 当前固定为 `global` |
| `max_records` | 最大记录数 | 全局最多保留多少条 `AgentTraceRecord`，默认 5000 |
| `updated_at` | 更新时间 | 设置最后更新时间 |
